# Tutorials

Tutorials teach through a guided exercise with a clear starting point and an observable result.

For a guided development setup, follow [Set up a development environment without VS Code](01-development-setup-without-vscode.md). You will start containers, initialize a bench, and open a local Frappe site.

For an introduction and quick demo commands, see [Getting started](../getting-started.md). The [Single Compose setup reference](../12-reference/10-single-compose-setup.md) describes the demo's services and volumes.

When writing a tutorial, choose one learning goal and guide the reader through the steps and expected results. See [Contribute to the documentation](../11-how-to/01-contribute-documentation.md) for writing guidance.
