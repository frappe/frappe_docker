Read this before step one

The ERPNext CRM flow cannot be completed by any single role. That is not a misconfiguration — it is the shipped permission model, and this playbook exists partly to show it. Two consequences catch everyone:

  • Sales Manager cannot create a Customer. It has read-only access. The Sales User creates customers; the manager cannot.
  • Sales User cannot create a Prospect. Also read-only. The account-level record belongs to the manager.

So a working sales seat needs Sales User + Sales Manager together. Your current login already has both — which is why solo mode works for everything except the four master-data doctypes.

Mode B — Role rehearsal

Create three test users with narrow role sets and hand the parts around. This is how you find out that your real sales team is one missing role away from a blocked pipeline — before they find out for you.

Part 0 sets the cast up. It needs an Administrator, and it is the only part you can skip entirely in Mode A.
